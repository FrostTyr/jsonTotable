# JSON → 表格

一个零依赖的单文件网页工具：粘贴 JSON，实时转成可排序、可搜索、可导出的表格。数据全部在浏览器本地处理，不上传。

## 使用方法

直接双击 `index.html` 用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开即可，无需安装任何东西。

## 功能

### 转换
- 粘贴（或拖入 `.json` 文件）后约 0.3 秒自动转换；数据量大时可关闭「自动转换」改用「转换」按钮
- 支持对象数组（最常用）、单个对象（自动作为一行）、数组内字段不一致时自动取字段并集，缺失显示 —
- JSON 有误时状态条变红并给出原因（部分浏览器可精确定位到行列）
- 「格式化」按钮美化输入的 JSON；「示例」填入演示数据；「清空」一键重置

### JSON 语法高亮
- 左侧输入框带实时语法着色：**键**（琥珀）、**字符串**（绿）、**数字**（蓝）、**true/false**（绿/红）、**null**（灰色斜体）、**符号**（灰），亮 / 暗主题各一套配色
- 输入、粘贴、格式化、拖入文件后即时刷新；与 JSON 是否合法无关，写错途中也有颜色
- 超大文本（>30 万字符）自动降级为无色，避免输入卡顿

### 展示模式（三选一）
| 模式 | 行为 |
| --- | --- |
| **分层展开**（默认） | 主表一行一条记录（结构不打乱）：嵌套对象拆成 `a.b.c` 点号列；**嵌套数组在对应行下方显示为独立的子表格**——各有各的表头和标题（如「订单 · 2 条」），子表格内还可继续嵌套子表格，多层递归，全部直接可见 |
| 拍平列 | 仅把嵌套对象拆成点号列，数组保留徽标 |
| 徽标 | 紧凑视图：嵌套值显示为 `{ } n 字段` / `[•] n 项` 徽标，点击弹出子表格浮层，可多层递归展开 |

分层展开说明：主表中数组字段单元格显示「↳ n 条」提示，子表紧跟该行下方（排序、搜索时随行整体移动）；同一行的多个数组各占一个子表，互不混合。状态条显示子表总数。

### 表格
- 点列头循环 升序 / 降序 / 取消（数字智能比较，空值恒排最后）
- 搜索框实时过滤行并高亮命中（全字段匹配）
- 「列 ▾」隐藏 / 显示指定列（菜单可连续勾选，不必反复打开）

### 单元格复制与框选（类 Excel）
- **双击单元格**：复制该单元格内容（徽标格除外，保持弹层行为）
- **按住拖动**：框选连续的矩形区域（跨行拖动时中间的子表行自动跳过），选中单元格蓝色高亮
- 复制选区：按 `Ctrl / ⌘ + C`，结果为 TSV，可直接粘贴进 Excel / WPS / 飞书表格
- `Esc` 或点击表格以外区域取消选区；焦点在 JSON 输入框 / 搜索框时，`Ctrl / ⌘ + C` 复制的是输入框内选中的文本，不会被表格选区劫持

### 复制与导出
- **复制 TSV**：粘进 Excel / WPS / 飞书表格直接成型（跟随当前过滤、排序、列显示）
- **复制 Markdown**：生成 Markdown 表格，可直接贴进文档
- **导出 CSV**：带 UTF-8 BOM，Excel 打开不乱码

### 其他
- 亮 / 暗色主题一键切换（跟随系统偏好，自动记忆）
- 窄屏（<900px）自动切换上下布局；左右分栏宽度可拖动调整

## 常见问题

- **粘贴后没反应？** 检查状态条是否提示 JSON 解析失败；也可以关闭自动转换后点「转换」。
- **复制/导出包含嵌套数据吗？** 复制与导出针对主表（数组字段导出为 JSON 文本）；需要看嵌套结构时用页面上的子表格，或框选/双击复制单个单元格。
- **复制到 Excel 中文乱码？** 用「导出 CSV」而不是手动复制网页文本。
