使用帮助

  • 自动转换：粘贴 JSON 后约 0.3 秒自动生成表格；数据量大时可关闭开关，改用「转换」按钮。
  • 支持格式：对象数组（最常用）、单个对象（自动作为一行）；各行字段不一致时自动取字段的并集，缺失显示 —。
  • 展示模式：「分层展开」（默认）保持数据结构——主表一行一条记录，嵌套对象拆成 a.b.c 点号列，嵌套数组在对应行下方显示为独立的子表格（各自有表头，可多层嵌套）；「拍平列」只拆对象、数组保留徽标；「徽标」为紧凑视图，点击 { } n 字段 / [•] n 项 徽标可弹出子表格（可多层递归）。
  • 语法高亮：左侧 JSON 输入框带语法着色——键、字符串、数字、true/false/null、符号各用不同颜色（亮 / 暗主题各一套），输入过程中实时刷新，与 JSON 是否合法无关。
  • 排序与搜索：点击列头切换 升序 / 降序 / 取消；搜索框实时过滤行并高亮命中。
  • 单元格复制：双击单元格复制其内容。
  • 框选复制：在表格里按住鼠标拖动，可像 Excel 一样选中连续的矩形区域（跨行时中间的子表行自动跳过）；松开后按 Ctrl / ⌘ + C 复制选区（TSV，可直接粘贴进 Excel / 飞书表格）；点击表格以外区域或按 Esc 取消选区（焦点在 JSON 输入框时 Ctrl / ⌘ + C 复制的是输入框里选中的文本）。
  • 列控制：「列 ▾」可隐藏 / 显示指定列。
  • 复制与导出：复制 TSV 可直接粘贴进 Excel / WPS / 飞书表格；复制 Markdown 用于文档；导出 CSV 自带 BOM，Excel 打开不乱码。
  • 隐私：全部转换在浏览器本地完成，无任何网络请求。
